# Batch 12 — Textile provenance gate

All candidates in this review were admitted only after an open/commercial-use provenance check. This file records the source family used for that gate; final library archival should still preserve the upstream license file with any approved binary/source package.

## Knit / colorwork — Soft Type Collection
- Designer: Sarah Cadigan-Fried / Soft Type Project.
- Families reviewed: Jacquarda Bastarda 9, Jersey 10, Jersey 15, Jersey 20, Jersey 25, Micro 5, Yarndings 12, Yarndings 20, plus their Charted siblings.
- Purpose: designed around knit colorwork / stitch-count grids; Charted siblings expose the stitch cells.
- Source transport in lab: `google/fonts` OFL directories.
- License: SIL Open Font License 1.1.
- Upstream project evidence: Soft Type repositories / Google Fonts OFL metadata.

## Historical cross-stitch — Advanced Cross-Stitch Fonts (ACSF)
- Author/project: Pierre Baudin / ACSF.
- Families reviewed: Adorable, Brave, Chic, Divine, Expressive, Festive, Gallant, Honorable, Irresistible.
- Provenance: the project reconstructs alphabet-primer patterns published before 1930 and describes those source patterns as public-domain cultural heritage; the resulting font software is released openly.
- Source: `pbaudin/ACSF`.
- License: SIL Open Font License 1.1; project documentation explicitly permits use of charts produced by the fonts for commercial purposes.

## Woven / material systems
### Hovden Stitch
- Designer: Rasmus Andersson.
- Source: `rsms/hovden-stitch`.
- Provenance: stitch/embroidery-derived personal typeface project originating in 2002.
- License: SIL Open Font License 1.1.

### Amakan
- Designer: Jad Maza; distributed by Tunera Type Foundry.
- Source: `jadmaza/amakan` plus Tunera's project page.
- Provenance: patterned after woven split-bamboo *amakan* wall mats used on traditional nipa huts in the Philippines; Sheet, Strips and Stripes are supplied styles.
- License: SIL Open Font License 1.1.

### Kobata
- Designer: Ariel Martín Pérez; distributed by Tunera Type Foundry.
- Provenance: rule-based geometric project whose designer explicitly cites calligraphy, embroidery and digital art among its visual/material references.
- Canonical project: Tunera / the designer's Kobata source project. The lab uses a webfont mirror only as transport for visual review, not as provenance authority.
- License: SIL Open Font License 1.1.

## Stitch-native machine-embroidery systems — Ink/Stitch
- Project: Ink/Stitch `embroidery-fonts`.
- Candidates reviewed: Bathaus FI, Pacificlo, Ambigüe, Barstitch Textured, Barstitch Mandala, Colorful, Sunset, Alchemy, Eloquent, Barstitch Cloudy.
- These are not being represented as ordinary desktop fonts. Their review cards use official Ink/Stitch production previews and link to the actual source directories containing stitch-aware SVG/source data and `font.json` metadata.
- Each selected candidate's `font.json` / per-font license identifies SIL Open Font License 1.1.
- Material-specific metadata verified during selection includes satin/bean/cross-stitch/guided/meander/tartan fill behavior, nominal size and allowed scaling where provided.

## Review integrity
- Acquisition status is intentionally not exposed in the voting UI.
- No synthetic bold/italic treatment is used.
- No image generation is used. The stitch-native preview images are official upstream production previews from Ink/Stitch.
