# Ruthie Open Font Library — Project Scope

## Canonical target

**250 approved font families** for Ruthie's personal open font library.

This supersedes the earlier 100-family target wherever older manifests or review pages still mention 100.

## Collection model

- Additive, not competitive. A YES means preserve the family for any future purpose; it does not replace, rank, or finalize another font.
- Any use is valid: Spatial Press, products, labels, editorial work, experiments, personal projects, historical reconstruction, interfaces, physical fabrication, or uses not yet imagined.
- Review continues in **large batches: normally 30 candidates at a time**, grouped into navigable story/material lanes. Move toward 40 when mobile loading remains reliable.
- Review decisions are YES / NO only, placed at the end of each card.
- Candidate acquisition status stays hidden during visual review.
- No image generation for typography review. Review actual font binaries / live web type; stitch-native systems may use official upstream production previews when no ordinary browser font exists.

## Admission gate

Before a YES becomes a retained library family:

1. Verify an open, commercial-use-compatible font license.
2. Preserve provenance: designer(s), source, historical/artistic/technical story, and canonical upstream location.
3. Preserve actual supplied binaries and, when available, sources, variable axes, OpenType features, specimens, FONTLOG/readme, and license files.
4. Flag ambiguity rather than handwave it; drop or quarantine a candidate if licensing cannot be made clear enough.
5. Keep review transport separate from provenance authority: mirrors may render a specimen, but retained archives should come from canonical sources.

## Discovery direction

Discovery is **story-first as well as form-first**. Do not merely escalate weirdness or fill conventional type categories.

Especially productive lanes include:

- exact historical revivals and reconstructed evidence
- machine/display ancestry: avionics, terminals, CRTs, teletext, instrumentation, printers, scientific equipment
- spacecraft, mission-control, observatory, meteorological, navigation, photographic and laboratory visual systems
- generative / parametric / variable type where axes represent meaningful behavior
- color fonts and COLRv1 systems, especially when palettes/layers encode state or material
- typography that computes, charts, encodes, substitutes, animates, or behaves like a tiny renderer
- fabrication-native lettering: engraving, plotters, Jacquard, weaving, knitting, embroidery, stencils, CNC, stamps, labelers
- institutional and civic lettering with strong provenance
- small independent artists, workshops, schools, research projects, archives and personal sites
- practical workhorses whenever Ruthie simply likes them

## Search method

Prefer starting from an artifact, technology, institution, event, physical process, or story and then asking whether its lettering has been reconstructed or released as open type. Search font files, source repositories, CSS @font-face declarations, project sites, academic/workshop archives, GitHub/GitLab, foundries, and personal sites rather than relying on generic font-directory rankings.

## Weird-font playgrounds

Approved fonts with unusually deep behavior should also appear in persistent non-voting playgrounds, reorganized by what they do rather than by review batch. Current labs cover dynamic color, parametric/variable distortion, and fonts that behave like small rendering/data engines.

## Embroidery lane

Machine-embroidery alphabets are preserved as a separate deferred lane when Ruthie does not want to review stitch files directly. When Embroidery/Embilliance work resumes, treat actual stitch geometry, density, underlay, fills, thread color and product-scale rendering as a separate visual system rather than assuming the ordinary font preview is the final output.
